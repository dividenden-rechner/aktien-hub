Häufige Fragen

Wie hoch ist die Dividende von Automatic Data Processing?

Im Geschäftsjahr 2025/26 zahlte Automatic Data Processing 6,64 US-Dollar je Aktie, das entspricht beim aktuellen Kurs einer Rendite von rund 2,1 %.

Wann zahlt Automatic Data Processing Dividende?

Automatic Data Processing zahlt die Dividende vierteljährlich, und zwar in den Monaten Januar, April, Juli und Oktober. Für die nächste Zahlung liegt noch kein beschlossener Termin vor. Ex-Tag und Zahltag stehen hier, sobald das Unternehmen sie veröffentlicht.

Wie hoch ist die Ausschüttungsquote von Automatic Data Processing?

Die Ausschüttungsquote liegt bei 60 % des Gewinns je Aktie (Geschäftsjahr 2026). Das ist ein solider Wert, die Dividende ist aus dem Gewinn gedeckt. Gemessen am freien Cashflow sind es 50 %.

Wie hoch ist das Dividendenwachstum von Automatic Data Processing?

Die Dividende je Aktie wuchs im letzten Jahr um 10,3 %, in den vergangenen fünf Jahren im Schnitt um 12,4 % pro Jahr und in den vergangenen zehn Jahren im Schnitt um 12,8 % pro Jahr. Automatic Data Processing hat die Dividende 51 Jahre in Folge erhöht.

Seit wie vielen Jahren erhöht Automatic Data Processing die Dividende?

Automatic Data Processing hat die Dividende 51 Jahre in Folge erhöht und zählt damit zu den Dividend Kings.

Wie wird die Automatic Data Processing-Dividende in Deutschland besteuert?

In den USA werden mit dem Formular W-8BEN 15 % Quellensteuer einbehalten. Diese wird auf die deutsche Abgeltungsteuer angerechnet, sodass in Deutschland noch rund 10 % plus Solidaritätszuschlag anfallen.

Ist die Dividende von Automatic Data Processing sicher?

Gemessen am freien Cashflow flossen im letzten Geschäftsjahr rund 50 % in die Dividende. Das ist gut gedeckt, der Cashflow lässt noch viel Spielraum. Der Gewinn je Aktie hat sich zuletzt um 8,2 % verändert.

Wächst das Geschäft von Automatic Data Processing?

Der Umsatz veränderte sich zuletzt um 6,7 % und der Gewinn um 8,2 %. Grundlage sind die Zahlen des letzten Geschäftsjahres gegenüber dem Vorjahr.

Wie lukrativ ist die Dividende von Automatic Data Processing?

Die Dividendenrendite liegt beim aktuellen Kurs bei rund 2,1 %. Kommt das durchschnittliche Dividendenwachstum der letzten fünf Jahre von 12,4 % dazu, ergibt sich grob eine Erwartung von etwa 14,5 % pro Jahr. Das ist eine Überschlagsrechnung ohne Kursentwicklung und ohne Gewähr.

Ist Automatic Data Processing im Vergleich zu anderen teuer?

Das KGV von Automatic Data Processing liegt bei 28,0. Im Median der Vergleichsgruppe „Software und Dienstleistungen“ (7 Firmen mit Kennzahl) liegt es bei 24,9, Automatic Data Processing also über dem Durchschnitt der Gruppe.
