# Vergleichsartikel (Peer Group)

Lege hier einen **Unterordner pro Vergleich** an (zum Beispiel `flugzeugbauer-q3-2026`) und lade zwei bis fünf Berichte als PDF hinein. Sobald die PDFs hochgeladen sind, startet der Vergleichs-Agent und schreibt einen Entwurf nach `content/magazin`.

Ohne PDFs geht es auch: Actions → **IR-Vergleich (Peer Group)** → Run workflow, dann Kürzel (z. B. `BA, AIR.PA`) oder Links eintragen und optional einen Fokus (zum Beispiel „Triebwerkshersteller zusammen mit Airbus").
